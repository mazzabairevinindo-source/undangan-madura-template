TEMPLATE UNDANGAN DIGITAL

Pembuat Undangan

Isi data pasangan sekali, lalu buat tautan undangan sendiri. Ulangi proses ini untuk pasangan berikutnya tanpa membuat website baru.

✓ Banyak pasangan✓ Tautan masing-masing✓ Gratis di GitHub Pages
01

Identitas mempelai

Nama dan keluarga kedua mempelai.

02

Semua tulisan undangan

Ubah judul, salam, kalimat, label, tombol, pilihan RSVP, dan teks penutup. Biarkan apa adanya jika ingin memakai teks bawaan.

Semua teks yang tampil pada halaman undangan dapat diubah di sini. Teks label di halaman admin hanya sebagai petunjuk pengisian dan tidak muncul kepada tamu.

03

Tanggal dan waktu

Tentukan tanggal acara dan jam yang dicantumkan untuk tamu.

Tanggal akad dan resepsi mengikuti tanggal pernikahan. Jam kedatangan ini ditampilkan sebagai informasi resmi di undangan.

04

Lokasi acara

Alamat dan tautan petunjuk lokasi.

05

Foto dan musik

Isi alamat file yang sudah diunggah ke repository atau alamat web publik.

Foto dan audio harus berupa file yang dapat dibuka melalui tautan publik. File foto kain batik dekoratif sudah termasuk dalam template.

06

Hadiah pernikahan

Bagian rekening dapat dibiarkan kosong jika tidak digunakan.

07

Konfirmasi kehadiran

Nomor WhatsApp penerima konfirmasi RSVP.

Gunakan format internasional, misalnya 6281234567890 tanpa tanda +, spasi, atau strip. RSVP akan dikirim langsung ke WhatsApp ini.

08

Buat tautan undangan

Setiap pasangan mendapatkan tautan dengan data sendiri.

09

Data undangan tersimpan di perangkat ini

Daftar ini hanya tersimpan pada browser/perangkat yang Anda gunakan.

Data tidak otomatis tersimpan di server GitHub. Simpan tautan undangan atau unduh JSON sebagai cadangan.

Catatan penggunaan

GitHub Pages adalah hosting statis. Halaman ini membuat tautan mandiri yang membawa data acara; tidak ada database online dan tidak ada akun admin yang melindungi halaman ini. Siapa pun yang mengetahui alamat pembuat undangan dapat menggunakannya. RSVP dikirim ke WhatsApp panitia.
