Buat Undangan

Hasilkan tautan tersendiri untuk pasangan ini.

Nama tamu menjadi bagian alamat. Panjang slug dibatasi maksimal 50 karakter. Jika dikosongkan, slug dibuat dari nama kedua mempelai.

Data undangan disimpan otomatis di Supabase. Tautan hanya berisi slug dan dibatasi maksimal 150 karakter total. Tidak perlu mengunggah JSON atau melakukan commit GitHub setiap kali membuat undangan. Simpan JSON hanya sebagai cadangan.
